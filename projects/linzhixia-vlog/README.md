# 林知夏 vlog — 项目总控

> 一期手把手教程视频：从写脚本到生成视频、音频旁白、BGM 的一条龙工作流。

---

## 项目定位

这不是"某某软件教程"，而是一个**完整的内容生产工作流演示**：

- 怎么写逐字稿（旁白脚本）
- 怎么从逐字稿生成视频画面脚本
- 怎么生成音频旁白（TTS / AI 配音）
- 怎么生成或选配 BGM
- 怎么把以上串成一条可复现的流程

目标受众：想用 AI 辅助做视频但不知道从哪开始的创作者。

## 约束与备忘

- 逐字稿控制在 **1 分钟左右**（约 200-250 字），太长没人看。
- 上一版旁白被评价"无病呻吟"，新版需要更直接、更有信息量。
- 教程的差异化在于：展示的是**整体工作流**，不是单一工具的操作指南。
